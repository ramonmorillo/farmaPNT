# Prompts de auditoría y mejora

## Prompt de auditoría

```text
Audita FarmaPNT sin modificar otras herramientas. Lee arquitectura y límites.
Ejecuta npm test y npm run test:browser. Verifica dos rutas de tres demos,
comprobaciones obligatorias, respuestas, retroceso sin ramas residuales,
interrupción y recuperación con una versión fija. Introduce una referencia
inexistente, un ciclo y un nodo aislado y comprueba su rechazo. Verifica
JSON, TXT y PDF por contenido. Busca XSS, transmisión de documentos, secretos
y afirmaciones falsas de autenticidad, vigencia o aprobación. Prueba teclado
y móvil. Distingue aprobados, fallidos y no ejecutados. No ocultes errores ni
elimines aserciones. Corrige problemas ordinarios y registra límites. No
publiques ni añadas tratamientos o reglas clínicas sin fuente y autorización.
```

## Prompt de excepción

```text
En una rama, aplica docs/tutorial/06-personalizacion.md. Añade una excepción
explícita a un documento ficticio, incrementa su versión y conecta una decisión
con un final de derivación. Conserva las tres demostraciones. No deduzcas
reglas clínicas. Prueba excepción, retroceso, otra respuesta y recuperación de
una sesión antigua con su propia versión. Comprueba exportaciones y tutorial.
```
